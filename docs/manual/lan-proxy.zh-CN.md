# 局域网代理

局域网代理可以把 Lemon 的 HTTP 代理监听在设备的局域网地址上，让同一 Wi-Fi 中的其他设备把 Lemon 作为代理使用。它适合调试没有运行 Lemon 的设备，或让外部测试设备共享当前的抓包、MITM 和重写链路。

## 开启前准备

确认 Lemon 设备与被调试设备连接到同一局域网，并确认当前网络允许设备互相访问。进入 **LAN Proxy** 后打开开关；服务启用时页面会显示 Server IP 和 HTTP Proxy Port。

端口可以修改，但必须使用合法端口。若服务已经运行，先停止服务再修改配置，避免客户端继续使用旧地址。

## 在其他设备上配置

以 iOS 为例：

1. 在 Lemon 的 LAN Proxy 页面打开服务并记下 Server IP 与端口。
2. 在另一台设备进入当前 Wi-Fi 的 HTTP Proxy 设置。
3. 选择手动配置，填入 Lemon 显示的 IP 和端口。
4. 保存后访问一个测试地址，回到 Lemon 请求列表确认流量出现。

如果开启了 Basic Authentication，还需要在客户端填写同一组用户名和密码。不要把代理端口直接暴露到不受信任的网络；局域网内的其他设备可能因此访问或观察经过 Lemon 的数据。

## 验证和排查

| 现象 | 检查方向 |
| --- | --- |
| 客户端无法连接 | 两台设备是否同网、IP 是否变化、防火墙或网络隔离是否阻止访问 |
| 可以连接但没有请求 | 客户端是否只配置了 HTTP、目标流量是否为 HTTPS、是否使用其他 VPN |
| HTTPS 无法查看正文 | 目标设备是否信任 Lemon CA，或目标 App 是否有证书绑定 |
| 认证失败 | Basic Authentication 是否已填完整，用户名和密码是否被客户端保存了旧值 |

局域网代理不会自动改变客户端已经建立的连接。修改端口、认证或证书后，重新连接 Wi-Fi 或重启目标 App，确保新设置真正生效。

## 使用结束

完成外部设备调试后关闭 LAN Proxy，恢复目标设备的代理设置，并清理不再需要的证书、Hosts 和 Rewrite 配置。关闭服务不会撤销已经安装在其他设备上的 CA 或代理设置，需要单独恢复。
