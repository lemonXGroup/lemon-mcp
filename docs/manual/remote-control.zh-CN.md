# 远程控制

远程控制会在 Lemon 设备上启动一个 Web Control 服务，让同一网络中的浏览器或受控客户端通过 HTTP 访问 Lemon 的控制端点。它是 Lemon MCP、官网控制台和自动化工具连接 App 的基础能力之一。

## 启动服务

进入 **Remote Controller**：

1. 设置监听端口，默认值为 `9999`；端口必须可用。
2. 打开服务开关。
3. 记录页面显示的 URL、Listening 状态和访问 Token。
4. 在浏览器或受支持的客户端中使用该 URL，并按要求提供 Token。

服务启动后页面会显示当前局域网地址。地址可能随 Wi-Fi 切换、网络重连或设备休眠而变化；连接失败时先刷新页面中的 Access Info。

## 认证与权限

访问 Token 是远程控制服务的凭据。不要把它放进公开截图、仓库、日志或聊天记录。关闭并重新启动服务可能生成新的访问凭据，具体以页面显示为准。

不同控制端点有不同能力边界：读取状态、查看请求、保存文件、执行重放、修改 Rewrite 或运行 SQL 的影响不同。远程客户端应只调用完成任务所需的最小能力，并在写操作后读取状态确认结果。

## 后台模式

页面提供 Picture-in-Picture 后台模式，用于在系统允许的情况下维持 Web 服务运行。它不是无限后台保证；系统资源、网络状态和 iOS 生命周期仍可能中断服务。需要稳定连接时，保持 Lemon 在前台并观察服务状态。

## 连接排查

- URL 无法打开：确认服务处于 Active、客户端与 iPhone 在同一网络、IP 和端口没有变化。
- 返回认证错误：使用当前页面的 Token，不要继续复用旧 Token。
- 能打开但接口被拒绝：检查调用方是否有对应能力或需要认证的端点。
- 服务启动后网络异常：检查端口冲突、其他 VPN / 代理以及局域网隔离。

远程控制暴露的是设备上的调试能力。只在可信局域网中使用，调试结束后关闭服务；不要为了方便把端口映射到公网，也不要将访问 Token 分享给不需要操作设备的人。

## 通过 LemonMCP 连接

当前访问口令为六位数字字符串，可能包含前导零。服务正常重启会复用已保存口令；显式“刷新口令”后旧口令立即失效，MCP 需要更新本机配置并重启。当前公开 MCP 尚无口令输入弹窗。完整步骤和错误分类见 [首次连接指南](../AI_GUIDE.zh-CN.md)。
