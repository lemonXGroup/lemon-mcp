# 文件

文件管理器用于浏览 Lemon 共享存储中的调试资源。它适合管理 Mock 数据、脚本依赖、模块包和调试产物，也支持创建目录、创建文件、编辑、上传、下载、分享和删除。

## 可以做什么

| 操作 | 适合用途 |
| --- | --- |
| 浏览目录 | 确认脚本、模块或导出文件的组织方式 |
| 新建文件夹 | 按项目或调试场景隔离资源 |
| 新建文件 / 编辑 | 修改文本配置、Mock 数据或辅助脚本 |
| 上传 | 将外部资源放入共享存储 |
| 下载 / 分享 | 将诊断产物交给其他工具或保存到系统位置 |
| 删除 | 清理不再使用的资源 |

文件视图会根据当前路径显示目录内容；进入文件后可以查看或编辑内容。大文件、二进制文件和不确定编码的内容不适合直接在编辑器中修改，先保留原文件或使用下载方式处理。

## 推荐的目录方式

可以按以下思路组织资源：

```text
debug/
  mock/
  scripts/
  modules/
  exports/
```

目录名称本身不会自动赋予脚本或模块特殊能力。脚本和模块仍需要通过对应的控制台功能完成校验、发布或安装；仅仅把文件放进某个目录不会让它自动运行。

## 编辑和分享前的检查

编辑前确认当前路径和文件名称，避免误改正在被任务或模块引用的资源。分享、上传或下载前检查内容中是否含有 Cookie、Authorization、设备地址、个人数据或服务端密钥。

文件管理器的删除是实际删除操作。对于仍可能被脚本、模块或调试流程使用的文件，先停用引用方并确认有可恢复副本，再执行删除。

## 通过自动化使用

如果由 AI 或远程控制接口操作文件，建议先列目录，再读取目标文件，最后才执行保存、上传或删除。写入后重新读取并核对内容，确认路径、字节数和编码符合预期。不要把“接口调用成功”直接当成“下游脚本已经加载”。

## 常见问题

- 看不到文件：确认当前目录、共享存储状态和名称大小写。
- 编辑后没有效果：检查实际引用路径，并重新加载使用该文件的脚本或模块。
- 上传后无法使用：文件存在不代表内容通过脚本、模块或运行时校验。
- 分享失败：先下载到系统可访问的位置，或检查文件类型和权限限制。
